# Illustration prompts and local SVG interpretations

These prompts describe the approved visual direction. No image-generation service was called. The portfolio now uses locally authored, responsive SVG interpretations of these briefs; they are original line-art assets, not generated raster artwork or reused reference images.

## Shared visual language

Minimalist editorial vector line-art illustration in a monochrome sepia palette. Use thin, elegant dark-brown continuous outlines with soft rounded forms and very limited solid brown shading. Use a warm ivory or pale beige background with subtle paper-like texture. Keep the composition spacious, calm, balanced, intelligent, and welcoming. Modern academic editorial illustration, clean hand-drawn vector appearance, no realistic shadows, no gradients, no photorealism, no 3D rendering, no text, no logos, no watermarks, high resolution.
